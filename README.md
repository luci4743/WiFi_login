# WiFi_login
This python project is to automate the process of connecting to LPU Wi-Fi and logging the web portal with your account


#Requirements:
Geckodriver(to control the firefox browser) => https://github.com/mozilla/geckodriver/releases
Recommended save path that aligns with the project is (C:\drivers\geckodriver.exe)
You will have to use other browsers, you have to get the corresponding drivers.

Following Python libraries:
Subprocess
Selenium


Restrictions:
1)This program is windows exclusive.
2)Only working with LPU wifi portal, you are free to modify to use it with other Wi-Fi Portals.


Steps to properly use this program.
1) Download this porgram and save it some location.
2) Download geckodriver as well and save it at the specified language (or edit it if you wish to do so)
3) Pip install the required libraries mentioned above.
4) Edit the program with your webportal username and password.
5) Optionally you can create a bat file and assign it some shortcut key to further automate & simplify the porcess
